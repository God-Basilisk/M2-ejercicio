how to use vite in vs code+
=========
I'll show you how to use Vite in VS Code step by step, from creating a project to running your website in the browser.

1. Install what you need
Visual Studio Code - Download and install on Windows | Microsoft Store
Visual Studio Code

Your code editor.

Download VS Code

Pengenalan Node JS Lengkap + Cara Install - Teziger Blog
Node.js (includes npm)

Runs the tools needed to create and launch your project.

Download Node.js

After installing Node.js, open VS Code.

2. Create a Vite project
In VS Code, open the terminal using Terminal → New Terminal from the top menu.

Type these commands one at a time:

Step 1 — Create the project

npm create vite@latest my-app

This creates a project folder named my-app.

Step 2 — Enter the folder

cd my-app

Step 3 — Install dependencies

npm install

Step 4 — Start Vite

npm run dev

Vite prints a local URL, usually http://localhost:5173/.

If the setup asks you to choose a framework, select Vanilla for plain HTML, CSS and JavaScript, or React if you want to build a component-based application.

3. Open your website
After running npm run dev, the terminal should show something similar to:

  VITE ready

  Local: http://localhost:5173/
Ctrl-click (or Cmd-click on Mac) the URL, or copy it into your browser.

You should see the starter page generated by Vite.

Keep the terminal running while you work.

4. Edit your website in VS Code
Your files will look something like this:

my-app/

src/

Your application code and styles.

main.js or main.jsx

style.css or index.css

index.html

package.json

The exact files depend on which framework you selected.

Try changing the page: open index.html for a Vanilla project, or your main component (often src/App.jsx) for React. Save your changes and Vite will update the browser automatically.

For example, in a React project, replace the contents of src/App.jsx with:

function App() {
  return (
    <main>
      <h1>Hello, Vite!</h1>
      <p>My first web application.</p>
    </main>
  );
}

export default App;

Save the file. Your browser should update without you needing to restart Vite.

5. What do you do after that?
Install a library: npm install package-name

Stop the server: press Ctrl + C in the terminal.

Start it again: run npm run dev.

Build for deployment: run npm run build.

I found one bug. Some entries contain a soft hyphen followed by a line break in the middle of a word, and your cleanText turns that into a space, so you get “Poké mon”. Replace cleanText in api.js with:

js
const cleanText = (text) =>
  text.replace(/\u00ad\n?/g, '').replace(/[\n\f]/g, ' ').replace(/\s+/g, ' ').trim();
